# CatchBan: The Creator's Workspace /  创作者素材工作台

CatchBan is an audio & visual asset workbench crafted exclusively for creators. It seamlessly integrates an array of creative tools within one workspace, covering one-click precise capture of ultra-high-definition videos, flexible archiving and efficient preview capabilities. No constant switching between different applications is required. Systematize scattered sparks of inspiration and turn them into tangible creative productivity. 

CatchBan 是专为创作者打造的视听素材工作台。从一键精准采集超清视频，到灵活归档与高效预览，工作台内置多款创作工具，彼此无缝联动。不必反复切换各类软件，系统化收纳零散灵感碎片，将灵感转变为实打实的创作生产力。

---

## ✨ CATCHBAN V2.1.1 Feature Highlights /  功能亮点

### 1. One-Click Direct Capture of Ultra HD Videos / 超清视频一键直采

It supports deep parsing of mainstream creative inspiration platforms: YouTube, Vimeo, Bilibili, XINPC, Digitaling, Xiaohongshu, Douyin, TikTok, Instagram and X (Twitter). Captured footage can reach up to 4K Ultra HD resolution and will be sorted together with local videos for unified management.

深度解析 YouTube、Vimeo、B站、新片场、数英网、小红书、抖音、TikTok、 Instagram、X/Twitter等创作者核心灵感阵地。支持最高 4K超清画质，并将采集结果与本地视频统一归类管理。

### 2. Customizable Download Formats & Resolution Options / 下载格式与画质选择

Choose video-only or audio-only mode based on how you intend to use the asset, and pick from available resolutions including 4K, 1080p and 720p to balance visual clarity, file size and processing speed.

根据素材用途选择视频或纯音频模式，并在可用范围内选择 4K、1080p、720p 等画质，兼顾清晰度、文件体积与处理速度。

### 3. Smart Embedded Browser for Content Parsing / 智能解析浏览器

If the target content requires login or verification, complete authentication directly within CatchBan’s built-in browser. Log in, play the desired video, then click Catch It to send the content into the capture queue automatically.

遇到需要登录或验证的内容时，可直接在 CatchBan 内置浏览器中完成操作。登录并播放目标视频后点击 Catch It，即可将当前内容交给采集流程处理。

### 4. One-Click Archiving for Video Links / 视频链接一键归档

Once a link is added, CatchBan automatically generates a dedicated link card that records source details, task status and follow-up actions centrally. These link cards can be managed within the workbench exactly like local video files.

添加链接后，CatchBan 会自动生成视频链接卡片，统一记录来源、状态和后续操作。链接卡片可以实现和本地视频一样在同工作台中进行管理。

### 5. In-Workbench Preview for Link Cards / 视频链接卡片在线预览

Preview link-based assets directly inside the workspace for supported sources. This avoids constant switching between browsers, Finder and media players, while preserving original source information intact.

对于支持预览的链接素材，可直接在工作区内打开卡片进行查看，减少在浏览器、Finder 和播放器之间反复切换，并保留原始来源信息。

### 6. Flexible Archiving for Video Assets /  视频素材灵活归档

Create folders sorted by project, theme, series or production stage. You may move, rename, restore and organize assets freely at any time.

素材可以按项目、主题、系列或制作阶段创建文件夹，随时移动、重命名、恢复或整理。

### 7. Blazing-Fast Native Video Preview/ 原生极速视频预览

Videos load using macOS native preview technology by default for ultra-fast opening and snappy interactive responses. For incompatible files unable to leverage native preview, CatchBan switches to its internal preview engine to maintain swift browsing performance.

视频优先使用 macOS 原生预览能力，打开速度快、操作响应直接。遇到原生路径不适用的素材时，CatchBan 会使用内置预览方案继续完成快速预览。

### 8. Intelligent Asset Organizer Assistant / 素材智能整理助手

CatchBan actively reminds you of assets missing metadata, duplicate files, archivable media from identical sources and unorganized content, so you can quickly identify priorities for your next workflow step.

CatchBan 会主动提示待补全元数据、重复文件、同来源归档候选和待整理素材，帮助你快速找到下一步最值得处理的内容。

### 9. Practical Frequently Used Creative Tools / 丰富的高频使用创作工具

- Video format conversion / 视频格式转换

- Video resolution modification / 修改视频分辨率

- Video frame rate remapping / 视频帧率重构

- Video segment trimming & export / 修剪视频片段并导出

- Animated GIF export / 导出动态 GIF 图

- Video keyframe extraction视频关键帧抓取

- Batch thumbnail generation / 批量缩略图

- Audio separation & extraction / 音频分离提取

### 10. Seamless Integration with Post-Production Software / 后期软件无缝对接

Assets stored in the workbench can be dragged directly into Premiere Pro, DaVinci Resolve, Final Cut Pro and other editing software for further editing. You may also trim clips, extract frames or convert formats inside CatchBan beforehand.

工作台中的素材可以直接拖入 Premiere Pro、DaVinci Resolve、Final Cut Pro 等后期软件继续剪辑，也可以先在 CatchBan 内完成片段、帧图或格式准备。

## 📺 Installation Steps / 安装方式

System Requirements: macOS 12 or later. Optimized for Macs equipped with Apple M-series chips; Intel-based Macs are not supported for the time being.

需要 macOS 12 或更高版本；适用于搭载 Apple M 系列芯片的 Mac；Intel芯片Mac暂不支持。

1. Open CatchBan.dmg

打开 CatchBan.dmg

2. Drag CatchBan.app into the Applications folder

将 CatchBan.app 拖入 Applications 文件夹

3. Launch CatchBan from Applications

从 Applications 启动 CatchBan

It is not recommended to run the application directly inside the DMG window. Always move CatchBan.app to Applications first before opening it.

建议不要直接在 DMG 窗口中运行应用。请先将 atchBan.app 拖入 Applications 后再打开。
